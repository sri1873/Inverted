# Inverted

A custom Information retrieval system implemented in Java to understand how search engines like Lucene and elastic search work internally.

This project focuses on core IR concepts: Inverted indexing, positional postings, BM-25 & TF-IDF ranking, boolean and phrase search - also explores segmentation and index persistence similar to Lucene.


# Motivation 

Search engines are widely used but remained as black boxes. This projects exists to help me understand 
 - How are documents indexed efficiently
 - What are some scoring and ranking functions available. 
 - How does Lucene efficiently use segmentation and immutable indexes 
 - How does phase search and positional highlighting work.
